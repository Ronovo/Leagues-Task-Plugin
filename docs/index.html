What it does

One sidebar panel that turns a scattered pile of Leagues tasks into something you can actually work through.

One unified list

Over 2,200 tasks drawn from four past Leagues events, merged so a task that appeared in more than one event is a single row.

Filter, then pick

Narrow by region, difficulty, and activity type, then roll a random task that fits — or browse the full filtered list.

Save and check off

Keep one saved task per difficulty tier and mark tasks complete against a running background log.

Autocomplete

Detects tasks it can confirm from your account — quests, skill levels, achievement diaries, combat achievements, boss kills, clue counts. It shows a preview first; nothing is written until you confirm.

Optional progress sync

Install Ronovo's Sync Tool alongside it to send your progress to a Personal RuneScape Tracker you host yourself. Without it, this plugin sends nothing.

Per character

Completions and saved tasks are scoped to each character, so an alt's progress never overwrites your main's.

Data & sync

Your progress is saved locally through RuneLite's own config. This plugin has no server settings and doesn't send your progress anywhere.

Syncing lives in a separate plugin, Ronovo's Sync Tool. It reads your completed tasks from this plugin's saved data and sends them, along with your quests, diaries, combat achievements and collection log, to your tracker.

With the Sync Tool turned on, the Sync Progress button on the start menu asks it to send your completed tasks. Without it, that button reads Install Ronovo's Sync Tool and explains how.

Install

The plugin is not on the RuneLite Plugin Hub yet. Until it is, you run it from source: a small Gradle command builds it and opens a RuneLite client with the plugin already loaded.

  1. Install JDK 11 (for example Eclipse Temurin 11) and make sure JAVA_HOME points at it.
  2. Get the source: on the GitHub page choose Code → Download ZIP and extract it, or clone the repository.
  3. Open a terminal in that folder and run ./gradlew run (on Windows, gradlew.bat run). The first run downloads what it needs, so give it a few minutes.
  4. Log in, then open Leagues Tasks from its icon in the sidebar.

Jagex accounts: the client started by ./gradlew run can't use the Jagex Launcher's login directly. Follow RuneLite's Using Jagex Accounts guide once (it adds --insecure-write-credentials to the launcher), and the client will pick up your saved login. That file lets anyone log in as you, so never share it.

Why not just drop a jar in? RuneLite only loads jars from its sideloaded-plugins folder in developer mode, which the normal launcher doesn't enable, so a copied jar is ignored.

Once the plugin is on the Plugin Hub, install it from there instead: wrench (Configuration) → Plugin Hub → search Leagues Tasks. This page will be updated when it is.

Syncing is optional and needs Ronovo's Sync Tool plus your own Personal RuneScape Tracker instance — a self-hosted character log and Grand Exchange tool. See the Sync Tool's README for setup.
