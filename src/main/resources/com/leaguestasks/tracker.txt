Tracker App

The Personal RuneScape Tracker is an optional companion web app. This
plugin works fully without it, but the tracker gives you a browsable
record outside the game.

It is more than Leagues tasks: it is a full character log, and it also
includes a Grand Exchange tool.

You host it yourself. It is designed to run locally or on your own
server; there is no public instance.

Once it is running, set its URL and your API token in the plugin
settings, then use the Sync Progress screen (or the Sync button on the
in-game collection log) to push your progress to it. On a friend's LAN
server the token is the shared SYNC_TOKEN; on a public site sign in and
copy your personal plugin token. Prefer HTTPS if the tracker is not on
this machine. The plugin only sends data to the tracker -- it never pulls
anything back.

Get it from GitHub:

[Personal RuneScape Tracker on GitHub](https://github.com/Ronovo/Personal-RuneScape-Tracker)
